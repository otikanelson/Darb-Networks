Frontend: User fills signup form\n   ↓\n2. Frontend: Call Firebase createUserWithEmailAndPassword()\n   ↓\n3. Firebase: Create user, send verification email\n   ↓\n4. Frontend: Get Firebase ID token\n   ↓\n5. Frontend: POST /api/auth/register with token + profile data\n   ↓\n6. Backend: Verify token signature\n   ↓\n7. Backend: Extract firebase_uid from token\n   ↓\n8. Backend: Create MySQL user linked to firebase_uid\n   ↓\n9. Backend: Return user profile (userType = \"investor\" by default)\n   ↓\n10. Frontend: Store token in localStorage\n```\n\n### Login Flow\n```\n1. Frontend: User enters email/password\n   ↓\n2. Frontend: Call Firebase signInWithEmailAndPassword()\n   ↓\n3. Firebase: Authenticate user\n   ↓\n4. Frontend: Get Firebase ID token\n   ↓\n5. Frontend: POST /api/auth/login with token\n   ↓\n6. Backend: Verify token signature\n   ↓\n7. Backend: Extract firebase_uid from token\n   ↓\n8. Backend: Lookup user in MySQL by firebase_uid\n   ↓\n9. Backend: Return user profile + update lastLoginAt\n   ↓\n10. Frontend: Store token in localStorage\n```\n\n### Protected Endpoint Access\n```\n1. Frontend: Retrieve token from localStorage\n   ↓\n2. Frontend: Include in Authorization header: Bearer <token>\n   ↓\n3. Backend: firebaseAuth.verifyFirebaseToken middleware\n   ↓\n4. Backend: Verify token signature using Google public keys\n   ↓\n5. Backend: Extract firebase_uid from token\n   ↓\n6. Backend: Lookup user in MySQL by firebase_uid\n   ↓\n7. Backend: Set req.userId, req.firebaseUid, req.userType\n   ↓\n8. Backend: Controller processes request\n   ↓\n9. Backend: Response sent\n```\n\n---\n\n## 📊 Key Metrics\n\n### Performance\n| Operation | Before (JWT) | After (Firebase) | Improvement |\n|-----------|------------|-----------------|-------------|\n| (Google public keys)\n3. **firebase_uid** is unique per user; use as lookup key\n4. **Middleware chain** matters; verify token before email verification\n5. **Error handling** must distinguish between 403 (no token) and 401 (invalid)\n\n### For Frontend Developers\n1. **Firebase ID tokens** expire every 1 hour; refresh manually\n2. **Email verification** is separate from authentication\n3. **Password reset** happens entirely in Firebase (no backend involved)\n4. **logout** is frontend operation (clear localStorage + Firebase signOut)\n5. **Token refresh** can be automated with interval or on 401 response\n\n### For DevOps/Infrastructure\n1. **Firebase credentials** must be in environment variables\n2. **Private key** needs newline conversion from .env\n3. **Token verification** is fast (< 10ms)\n4. **No session storage** needed (Firebase tokens are stateless)\n5. **Monitoring** should track auth success/failure rates\n\n---\n\n## 🐛 Troubleshooting Guide\n\n### \"Firebase Admin SDK is not initialized\"\n- **Cause:** Missing .env variables\n- **Solution:** Add FIREBASE_PROJECT_ID, FIREBASE_CLIENT_EMAIL, FIREBASE_PRIVATE_KEY\n\n### \"User not found in database\"\n- **Cause:** Firebase token valid, but no MySQL profile\n- **Solution:** Call POST /api/auth/register to create profile\n\n### \"Email verification required\"\n- **Cause:** Attempting sensitive operation without verified email\n- **Solution:** Click email verification link, then call POST /api/auth/verify-email\n\n### \"Invalid or expired token\"\n- **Cause:** Token expired (1 hour) or corrupted\n- **Solution:** Call Firebase getIdToken(true) to refresh, retry\n\n### \"No token provided\"\n- **Cause:** Missing Authorization header\n- **Solution:** Include `Authorization: Bearer <FIREBASE_ID_TOKEN>` in request\n\n---\n\n## 🎉 Success Criteria\n\n✅ **All criteria met:**\n- [x] Firebase handles all authentication\n- [x] MySQL maintains user profiles and roles\n- [x] Email
