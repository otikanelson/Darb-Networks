📞 QUICK SUPPORT
================================================================================

PROBLEM: "Firebase not initialized"
SOLUTION: Check .env.local or .env has all variables. Restart dev server.

PROBLEM: "Invalid ID token"
SOLUTION: Backend missing Firebase credentials in .env or Vercel env vars.

PROBLEM: "Cannot register/login"
SOLUTION: Ensure both backend and frontend are running and connected.

PROBLEM: "Dashboard shows 503"
SOLUTION: Backend not initialized. Check backend logs for Firebase errors.

PROBLEM: "CORS errors"
SOLUTION: Frontend URL not in ALLOWED_ORIGINS. Update backend env var.

For detailed troubleshooting, see: DEPLOY_TO_VERCEL.md (Troubleshooting section)
