# Firebase Configuration - Quick Start Card\n\n## 🚀 What You Need to Get from Firebase Console\n\nThree values from Firebase Console → Project Settings → Service Accounts → Generate New Private Key:\n\n### 1. FIREBASE_PROJECT_ID\nFind in downloaded JSON:\n```json\n\"project_id\": \"darb-networks-xxxxx\"\n```\nValue to use: `darb-networks-xxxxx`\n\n### 2. FIREBASE_CLIENT_EMAIL\nFind in downloaded JSON:\n```json\n\"client_email\": \"firebase-adminsdk-abcde@darb-networks-xxxxx.iam.gserviceaccount.com\"\n```\nValue to use: `firebase-adminsdk-abcde@darb-networks-xxxxx.iam.gserviceaccount.com`\n\n### 3. FIREBASE_PRIVATE_KEY\nFind in downloaded JSON:\n```json\n\"private_key\": \"-----BEGIN PRIVATE KEY-----\\nMIIEvQIBADANBgkq...many lines...-----END PRIVATE KEY-----\\n\"\n```\nValue to use: Copy the entire thing including `-----BEGIN...-----END-----` and keep `\\n` as literal backslash-n\n\n---\n\n## 📝 Add to backend/.env\n\n```env\nFIREBASE_PROJECT_ID=darb-networks-xxxxx\nFIREBASE_CLIENT_EMAIL=firebase-adminsdk-abcde@darb-networks-xxxxx.iam.gserviceaccount.com\nFIREBASE_PRIVATE_KEY=-----BEGIN PRIVATE KEY-----\\nMIIEvQIBADANBgkq...\\n-----END PRIVATE KEY-----\\n\n```\n\n---\n\n## ✅ Test It Works\n\n```bash\nnode -e \"const { getAuth } = require('./backend/config/firebase'); getAuth(); console.log('✅ Firebase initialized!');\"\n```\n\nExpected output: `✅ Firebase initialized!`\n\n---\n\n## ✅ Run Tests\n\n```bash\nnpm run test:firebase\n```\n\nExpected: All tests passing ✅\n\n---\n\n## 🌐 Frontend Configuration\n\nGet from Firebase Console → Project Settings → General → Your Apps → Web:\n\nAdd to `frontend/.env.local`:\n\n```env\nREACT_APP_FIREBASE_API_KEY=AIza...\nREACT_APP_FIREBASE_AUTH_DOMAIN=darb-networks-xxxxx.firebaseapp.com\nREACT_APP_FIREBASE_PROJECT_ID=darb-networks-xxxxx\nREACT_APP_FIREBASE_STORAGE_BUCKET=darb-networks-xxxxx.appspot.com\nREACT_APP_FIREBASE_MESSAGING_SENDER_ID=123456789\nREACT_APP_FIREBASE_APP_ID=1:123456789:web:abcdef123456\n```\n\n---\n\n## 📋 Setup Checklist\n\n- [ ] Download JSON from Firebase Console\n- [ ] Extract FIREBASE_PROJECT_ID\n- [ ] Extract FIREBASE_CLIENT_EMAIL\n- [ ] Extract FIREBASE_PRIVATE_KEY (keep \\n as literal)\n- [ ] Add to backend/.env\n- [ ] Test with node command\n- [ ] Enable Email/Password in Firebase Authentication\n- [ ] Create web app for frontend\n- [ ] Add frontend config to frontend/.env.local\n- [ ] Run npm run test:firebase\n- [ ] All tests passing ✅\n\n---\n\n## 🔗 Documentation\n\nFull guide: `backend/FIREBASE_SETUP_CHECKLIST.md`\n\nMigration overview: `backend/FIREBASE_MIGRATION_COMPLETE.md`\n\nFrontend guide: `frontend/FIREBASE_AUTH_GUIDE.md`\n"
